# 📊 Sales Performance Dashboard – Microsoft Excel

## Project Overview
This project focuses on analyzing sales performance using Microsoft Excel. An interactive dashboard was developed to transform raw sales data into meaningful business insights and support data-driven decision-making.

## 🎯 Project Objectives
- Analyze overall sales and profit performance.
- Identify top-performing and low-performing product categories.
- Understand regional sales and profitability.
- Analyze customer segment performance.
- Track sales trends over time.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers and Timelines
- VBA Macros

## 📈 Key Performance Indicators (KPIs)
- Total Sales
- Total Orders
- Total Profit
- Profit Margin
- Average Sales
- Total Quantity

## 📊 Dashboard Features
- Region-wise Sales and Profit Analysis
- Customer Segment Analysis
- Monthly Sales Trends
- Top 5 and Bottom 5 Sub-category Analysis
- Interactive Filters and Slicers
- Dynamic Dashboard Navigation

## 💡 Key Learnings
- Data organization and analysis using Excel.
- Building interactive dashboards.
- Creating meaningful business visualizations.
- Using Pivot Tables and Pivot Charts.
- Understanding business performance through KPIs.
